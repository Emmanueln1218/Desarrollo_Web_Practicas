    🏗️ HTML - HyperText Markup Language

    HTML es el lenguaje de marcado estándar para crear páginas web. Describe la estructura de una página web mediante etiquetas.

    Estructura Básica de un Documento HTML

    <!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi Página</title>
</head>
<body>
    <!-- Contenido aquí -->
</body>
</html>

    🎨 CSS - Cascading Style Sheets

    CSS es el lenguaje de hojas de estilo en cascada que describe cómo se deben mostrar los elementos HTML en la pantalla, papel u otros medios.

    ¿Qué es CSS?
    CSS controla el diseño, colores, fuentes, espaciado y disposición de múltiples páginas web simultáneamente.

    Sintaxis Básica de CSS

    /* Selector { propiedad: valor; } */

h1 {
    color: blue;
    font-size: 24px;
}

    Tres Formas de Agregar CSS

    1. CSS Externo (Recomendado)

    <!-- En el <head> del HTML -->
<link rel="stylesheet" href="estilos.css">

    2. CSS Interno

    <style>
    body {
        background-color: #f0f0f0;
    }
</style>

    3. CSS En Línea (No recomendado)

    <p style="color: red; font-size: 16px;">Texto</p>

    Selectores CSS Principales

    Selector Descripción Ejemplo
    * Selector universal (todos los elementos) * { margin: 0; }
    elemento Selecciona por etiqueta HTML p { color: blue; }
    .clase Selecciona por clase .boton { background: red; }
    #id Selecciona por ID (único) #principal { width: 100%; }
    .cl1.cl2 Elemento con ambas clases .activo.visible { }
    selector1, selector2 Múltiples selectores h1, h2, h3 { color: blue; }
    padre hijo Descendiente (hijo, nieto, etc.) div p { color: red; }
    padre > hijo Hijo directo ul > li { list-style: none; }
    hermano + hermano Hermano adyacente h1 + p { margin-top: 0; }
    hermano ~ hermano Hermanos siguientes h1 ~ p { color: gray; }
    [atributo] Elemento con atributo [href] { color: blue; }
    [atributo="valor"] Atributo con valor exacto [type="text"] { }
    :hover Cuando el mouse está encima a:hover { color: red; }
    :active Elemento siendo activado button:active { }
    :focus Elemento enfocado input:focus { border: 2px solid blue; }
    :first-child Primer hijo li:first-child { }
    :last-child Último hijo li:last-child { }
    :nth-child(n) n-ésimo hijo li:nth-child(2) { }
    :not(selector) Niega el selector p:not(.intro) { }
    ::before Pseudo-elemento antes h1::before { content: "★ "; }
    ::after Pseudo-elemento después a::after { content: " →"; }

    /* VISIBILIDAD Y DISPLAY */
    visibility: visible;           /* Visible (ocupa espacio) */
    visibility: hidden;            /* Oculto (ocupa espacio) */
    display: none;                 /* No se muestra (no ocupa espacio) */
    
    /* CURSOR */
    cursor: pointer;               /* Manito (link) */
    cursor: default;               /* Flecha normal */
    cursor: text;                  /* I-beam (texto) */
    cursor: not-allowed;           /* Prohibido */
    cursor: grab;                  /* Mano abierta (arrastrar) */
    cursor: grabbing;              /* Mano cerrada (arrastrando) */
    cursor: wait;                  /* Reloj de arena */
    cursor: help;                  /* Signo de interrogación */
    
    /* SELECCIÓN DE TEXTO */
    user-select: none;             /* No se puede seleccionar */
    user-select: text;             /* Se puede seleccionar */
    user-select: all;              /* Selecciona todo al hacer click */
    
    /* PUNTERO DE EVENTOS */
    pointer-events: none;          /* No recibe clicks */
    pointer-events: auto;          /* Recibe clicks (default) */
    
    /* RESIZE (redimensionar) */
    resize: both;                  /* Horizontal y vertical */
    resize: horizontal;            /* Solo horizontal */
    resize: vertical;              /* Solo vertical */
    resize: none;                  /* No redimensionable */
    
    /* SCROLL */
    scroll-behavior: smooth;       /* Scroll suave */
    overflow-x: hidden;            /* Oculta scroll horizontal */
    overflow-y: auto;              /* Scroll vertical automático */
    
    /* LISTAS */
    list-style: none;              /* Sin viñetas */
    list-style-type: disc;         /* Círculo relleno */
    list-style-type: circle;       /* Círculo vacío */
    list-style-type: square;       /* Cuadrado */
    list-style-type: decimal;      /* Números */
    list-style-type: lower-alpha;  /* Letras minúsculas */
    
    /* TABLAS */
    border-collapse: collapse;     /* Bordes colapsados */
    border-collapse: separate;     /* Bordes separados */
    border-spacing: 10px;          /* Espacio entre celdas */
    table-layout: fixed;           /* Layout fijo */
    table-layout: auto;            /* Layout automático */
    
    /* OUTLINE (borde exterior) */
    outline: 2px solid blue;       /* Borde exterior */
    outline-offset: 3px;           /* Separación del outline */
    outline: none;                 /* Sin outline (cuidado con accesibilidad) */
    
    /* APARIENCIA */
    appearance: none;              /* Sin estilo nativo del navegador */
    
    /* CONTENIDO */
    content: "texto";              /* Inserta contenido (::before/::after) */
    content: url(imagen.png);      /* Inserta imagen */
    content: attr(data-texto);     /* Inserta valor de atributo */
    
    /* COLUMNA */
    column-count: 3;               /* Número de columnas */
    column-gap: 40px;              /* Espacio entre columnas */
    column-rule: 2px solid #ccc;   /* Línea entre columnas */
    
    /* OBJECT-FIT (imágenes/video) */
    object-fit: cover;             /* Cubre el contenedor */
    object-fit: contain;           /* Contiene sin recortar */
    object-fit: fill;              /* Estira para llenar */
    object-fit: none;              /* Tamaño original */
    
    /* WHITE-SPACE (espacio en blanco) */
    white-space: normal;           /* Normal */
    white-space: nowrap;           /* Sin saltos de línea */
    white-space: pre;              /* Preserva espacios y saltos */
    white-space: pre-wrap;         /* Preserva pero permite wrap */
    
    /* WORD-BREAK */
    word-break: break-all;         /* Rompe palabras largas */
    word-break: keep-all;          /* Mantiene palabras intactas */
    
    /* TEXT-OVERFLOW */
    text-overflow: ellipsis;       /* Puntos suspensivos (...) */
    text-overflow: clip;           /* Corta el texto */
}
